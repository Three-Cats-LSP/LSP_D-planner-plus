# V4 Seven-Lens Records

This directory is the authoritative home for new V4 risk-first cycle records.

Rules:

- Use `Rxx` cycle IDs from `docs/audit-units.json`.
- Keep one JSON record per cycle in this directory.
- Do not mirror new V4 JSON records under `docs/seven-lens-reports/`.
- Treat old `cycle-*.json` records as frozen historical evidence.
- Record findings, fixes, regressions, and verification in the single V4 record.
- Close a V4 cycle only after targeted regressions plus static and CI gates pass.
